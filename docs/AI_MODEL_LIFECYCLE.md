# AI Model Lifecycle

The active model is `BASELINE_MT5_H1_V1`, a deterministic baseline strategy.

Challengers must be trained offline from stored DEMO/historical datasets, backtested chronologically, validated out-of-sample, tested with walk-forward evaluation, and compared against the Champion using net P&L, expectancy, profit factor, drawdown, stability, SL/TP hit rates, MFE, and MAE.

No online self-modifying AI is implemented.
